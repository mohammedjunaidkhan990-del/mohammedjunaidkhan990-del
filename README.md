I am a Software Engineer at Capgemini, specializing in backend engineering 
and distributed systems. I build production-grade microservices using Java, 
Spring Boot, and Spring Cloud, and I integrate Generative AI into real-world 
applications using LangChain4j and Azure OpenAI.

My focus is simple — build things that scale, perform, and solve real problems.

---

### What I build

My work lives at the intersection of **backend engineering** and **AI**.

On the backend, I design microservices that are secure, scalable, and production-ready — Spring Boot, Spring Cloud, JWT, Redis, Flyway, the works. On the AI side, I have been exploring how large language models can be wired into real applications — not just as a chatbot, but as actual intelligent agents that reason, retrieve, and respond.

Three projects that defined my journey so far:

**SpringSweets** — Started as a simple e-commerce idea. Ended up as a full microservices platform with 8 services, Stripe payments, Cloudinary uploads, Redis caching, and a React frontend. Every service taught me something new about distributed systems.

**RAG HR Assistant** — My first serious dive into Generative AI. Built a system where employees can ask questions about their HR documents in plain English. Behind the scenes: PDF chunking, vector embeddings, cosine similarity search, and Azure OpenAI doing the heavy lifting. The moment it answered a complex HR query correctly, I was hooked on AI engineering.

**Multi-Agent Career Platform** — Took the AI work further. Built 4 specialized agents — a Skill Gap Advisor, a Mock Interviewer, a Salary Advisor, and a Master Agent that uses the LLM itself to decide which agent should handle your message. No hardcoded routing rules. Just intelligence.

---

### Where I am going

I want to keep building at the edge of backend engineering and AI. The space where microservices meet intelligent agents, where Spring Boot meets LangChain4j, where real engineering meets real intelligence — that is where I want to be.

I am not done learning. I am just getting started.
